# Руководство пользователя LintelCreator v3

Автоматическая раскладка перемычек в Autodesk Revit

Редакция от 27 октября 2026 года

Руководство описывает подготовку модели, подбор и редактирование комплектов, размещение новых перемычек, замену существующих, нумерацию и оформление. Названия полей и сообщений приведены в соответствии с интерфейсом версии v3.

Для первого запуска выполните последовательность из раздела 3. Для изучения отдельных кнопок используйте разделы 4–8, для устранения ошибок — раздел 13. Особенности текущей реализации, которые влияют на результат, собраны в разделе 14.

## 1 Назначение и основные понятия

Плагин собирает дверные и оконные проёмы, а также поддерживаемые витражи со стеной-основой; определяет геометрию стены и наличие опирающихся плит; предлагает комплекты перемычек из каталога; создаёт составные типы и размещает экземпляры в Revit. Уже установленные перемычки можно проверить и заменить. Отдельные команды заполняют параметры, нумеруют элементы и формируют оформление.

**Проём** — объект, для которого требуется перемычка. После объединения соседних объектов одна запись может представлять сборный проём.

**Группа проёмов** — карточка одинаковых по признакам подбора записей. Настройки и активный вариант относятся ко всей группе. Число «экз.» показывает количество записей размещения, а не обязательно количество исходных дверей и окон.

**Единичная перемычка** — вложенный элемент: брусок, плита, уголок, швеллер и другой поддерживаемый элемент каталога.

**Комплект** — упорядоченный набор единичных перемычек и зазоров по толщине стены. В модели он представлен одним экземпляром составного семейства.

**Вариант** — сохранённый в текущем окне состав комплекта для группы. У каждой группы свой активный вариант. Редактор справа показывает рабочую копию выбранного варианта.

**Готовый тип** — составной тип, уже загруженный в проект. Выбор готового типа загружает его состав в редактор. Для новых проёмов этот выбор нужно сохранить в вариант.

**Опирание 0, 1, 2** — количество сторон стены, на которых плагин обнаружил опирающиеся плиты. Это не длина опирания самой перемычки на простенки. Табличное опирание перемычки на простенки учитывается отдельно при выборе длины.

**Несущая зона** — требуемая ширина несущей части комплекта по толщине стены. В интерфейсе стороны 1 и 2 определяются ориентацией проёма и стены; они не имеют постоянного соответствия «слева на экране» и «справа на экране».

Геометрический подбор использует характеристики каталога. Команда не выполняет самостоятельный расчёт здания и нагрузок из расчётной модели. Окончательный состав и конструктивное решение проверяет проектировщик.

## 2 Подготовка модели

### 2.1 Что должно быть в проекте

Откройте рабочий документ Revit. Для размещения необходимы загруженные единичные семейства и хотя бы одно подходящее составное семейство категории «Несущий каркас». У типов составного семейства значение параметра «Модель» должно быть «Перемычки составные».

Каталог LintelUnitCatalog_v3.json загружается из встроенного ресурса сборки. Если ресурс отсутствует, плагин ищет одноимённый файл рядом с DLL. Наличие позиции в каталоге само по себе не загружает соответствующее семейство в Revit. Плагин может рассчитать вариант, но затем сообщить об отсутствии вложенного типа при размещении.

Для оформления потребуются семейство марки «ADSK_Марка_Балка» с типом **«ZH_Перемычка»**, тип разреза «Номер вида», шаблон разреза «4_К_Пр», тип видового экрана «Без названия». Для размещения разрезов на листе нужны ведомости с именами, содержащими «Ведомость_Пр_выше 0,00» и/или «Ведомость_Пр_ниже 0,00».

Если «Номер вида» или «4_К_Пр» отсутствуют, команда разрезов пытается создать их из существующего типа разреза и шаблона разреза. Копирование произвольного шаблона не гарантирует нужное графическое оформление: проверьте результат.

### 2.2 Какие объекты попадают в сбор

| Объект | Условия включения |
| --- | --- |
| Дверь | Самостоятельный экземпляр категории дверей, размещённый в поддерживаемой невитражной стене |
| Окно | Те же условия; семейства, содержащие «Угловое» в имени, исключаются |
| Витраж | Стена витражного типа; без «Лоджий» в имени и без кода типа 211.002; должна быть найдена обычная стена-основа |
| Стена-основа | Толщина не менее 88 мм; тип не содержит исключаемые фрагменты, кроме специального случая ПРГ_КЛД |

Из стен исключаются типы с фрагментами «_ПГП_», «_ГКЛ_», «_ФСД_», «_ПРГ_» без учёта регистра. Типы с «ПРГ_КЛД» разрешены, для них принудительно принимается опирание 0. Вложенные двери и окна не рассматриваются как самостоятельные проёмы.

Если объект не имеет доступных габаритов, подходящей основы, положительной ширины либо его стена тоньше 88 мм, он пропускается. Счётчик «пропущено» относится к объектам, отброшенным на этапе сбора; предварительно исключённые категории и семейства могут в этот счётчик не попасть.

Связанные модели не обходятся отдельным сборщиком. Данные проёмов, плит и перемычек для описанных операций берутся из активного документа.

### 2.3 Как задать область сбора

1. Для обработки конкретных проёмов выделите их в Revit перед запуском команды.
2. Для обработки вида снимите выделение поддерживаемых проёмов и откройте вид, на котором они видимы.
3. Запустите команду LintelCreator v3 из установленной панели FerrumAddin.

При запуске запоминаются ID поддерживаемых проёмов в выборе. Если такие ID есть, используются они. Если их нет, собираются поддерживаемые объекты активного вида. Выбор одних только перемычек перед запуском не ограничивает сбор связанными с ними проёмами.

**Обновление использует исходный выбор.** Кнопка «Обновить» не заменяет сохранённый набор ID новым выделением Revit. Чтобы перейти к другому набору выбранных проёмов, закройте окно и запустите команду заново. Если исходного выбора не было, при обновлении используется активный на этот момент вид.

### 2.4 Подготовка опирающихся плит

Для определения опирания рассматриваются элементы категории «Несущий каркас» с кодами ZH_Код_Тип_Число или ZH_Код_Тип в диапазонах 311 ≤ код < 312 либо 317 ≤ код < 318. Геометрия должна содержать доступное объёмное тело Solid.

Параметры «Опирание 1 итог» и «Опирание 2 итог» должны иметь положительные и совпадающие значения. Разница более 0,5 мм считается ошибкой. Вначале читаются параметры типа, затем экземпляра. Если параметр полностью отсутствует или не поддерживает чтение, предусмотрено резервное значение 120 мм; существующий параметр с нулём или непонятным текстом резервным значением не исправляется.

Сначала проверяйте плиты и их параметры, затем повторяйте сбор. Кнопка «Текущий» пересчитывает вариант по уже собранным данным и не перечитывает геометрию модели.

## 3 Полный порядок работы

### 3.1 Новые перемычки

1. Подготовьте семейства, проёмы, стены и параметры плит. Сохраните модель.
2. Задайте область сбора выбором проёмов либо активным видом и запустите команду.
3. Дождитесь окончания «Сбора проёмов» и «Расчёта вариантов».
4. Откройте вкладку «Проёмы без перемычек». Проверьте число записей, ширину проёмов, стену, толщину и опирание.
5. Выберите карточку. При необходимости переключите «Кирпич 65 мм», «Кирпич 88 мм» или «Перегородки», настройте допуск. Эти изменения пересчитывают текущую группу.
6. Если настройки должны применяться ко всем группам активной вкладки, нажмите «Пересчитать все». Поиск и фильтры не ограничивают этот пересчёт.
7. Выберите подходящий вариант в средней панели. Проверьте состав, длины и расположение несущей части.
8. При необходимости измените комплект справа, опорные подушки, планки и смещение. Выйдите из изменяемого числового поля, чтобы значение применилось.
9. Нажмите «Сохранить изменения варианта». Сохранение требуется до переключения карточки, выбора другого варианта и запуска размещения.
10. Повторите проверку для остальных групп. Установите флажки у групп, которые нужно разместить.
11. Проверьте скрытые фильтром отметки. Размещение использует все отмеченные группы без существующих перемычек, включая скрытые поиском.
12. Нажмите «Создать типы и проставить». Прочитайте отчёт и при необходимости сохраните TXT.
13. Проверьте геометрию на плане, разрезе и в 3D. Успешные группы перейдут в список существующих перемычек.
14. Выполните оформление в порядке из раздела 10.9 и сохраните проект Revit.

### 3.2 Существующие перемычки

1. Откройте вкладку «Существующие перемычки» и выберите нужную запись.
2. Изучите текущий тип и сообщения о соответствии. Средняя панель может сразу показывать рассчитанный вариант для замены.
3. Для просмотра именно установленного состава нажмите «Вернуть тип».
4. Выберите расчётный вариант, готовый тип из «Доступных типов» либо отредактируйте состав вручную.
5. Проверьте имя и отличия от существующего типа, включая зазоры, планку, высоты и опорные подушки.
6. Если доступна стратегия конфликта имён, выберите «Заменить на новое» или «Добавить номер к имени» с учётом раздела 8.3.
7. Нажмите «Заменить перемычки». Команда относится к перемычкам активной записи, а не к флажкам новых проёмов.
8. Проверьте сообщение о количестве заменённых экземпляров и геометрию в модели. После изменения типов при необходимости повторите нумерацию и оформление.

## 4 Устройство главного окна

Заголовок окна — «Автоматическая раскладка перемычек — v3». Окно немодальное: между действиями можно возвращаться в Revit. Во время сбора, расчёта и размещения основная рабочая область временно блокируется.

| Область | Что содержит | Для чего используется |
| --- | --- | --- |
| Верхняя строка | Название этапа, полоса прогресса, обработанное и общее количество, «Собрано · N проёмов» | Контроль готовности данных |
| Левая колонка «Проёмы» | Сводка групп и проёмов, длительность сбора, обновление, поиск, статусы, сортировка, две вкладки | Поиск группы и выбор объектов для размещения |
| Средняя колонка «Варианты раскладки» | Геометрия выбранной группы, настройки подбора, варианты и схема | Выбор активного расчётного решения |
| Правая колонка «Редактор комплекта» | Имя, готовые типы, строки состава, ширина и дополнительные параметры | Изменение комплекта и проверка конфликтов |
| Сервисная полоса | Переключатель разделения и семь команд оформления | Обработка параметров и документации |
| Нижняя полоса | Закрытие, сохранение или замена, создание и размещение | Применение подготовленного решения |

Ширину колонок можно менять перетаскиванием вертикальных разделителей. Списки прокручиваются; «Доступные типы» расположены горизонтально и поддерживают прокрутку колёсиком. Наведите курсор на усечённое имя или карточку, чтобы прочитать подсказку.

В сводках количество проёмов считается после объединения близких исходных объектов. Количество групп — число карточек, а количество созданных перемычек — число экземпляров составных семейств. Эти значения могут отличаться.

## 5 Панель Проёмы

### 5.1 Обновление и вкладки

**«Обновить».** Повторно собирает проёмы, геометрию, плиты и существующие перемычки; обновляет кэш готовых типов; затем запускает пересчёт активной вкладки. Ранее рассчитанные и вручную сохранённые варианты при новом сборе не переносятся. Флажки восстанавливаются только для групп с совпавшим внутренним ключом.

Списки опорных подушек и планок формируются при открытии окна. Если во время работы были загружены новые такие семейства, переоткройте плагин, чтобы получить актуальные списки.

**«Проёмы без перемычек (N)».** Записи, над которыми не обнаружена поддерживаемая существующая перемычка. Здесь доступны флажки и создание новых экземпляров.

**«Существующие перемычки (N)».** Записи с обнаруженными перемычками. Здесь применяется замена активной записи. Число N — количество записей проёмов, а не обязательно число найденных экземпляров перемычек.

### 5.2 Содержимое карточки

Карточка показывает вид и ширину проёма, тип и толщину стены, опирание 0/1/2, количество экземпляров, статус. У существующей перемычки дополнительно выводится имя установленного типа. В подсказке доступны семейство и тип исходного проёма, его ID, а на второй вкладке — также типы и ID перемычек.

**Нажатие на карточку** делает группу активной для просмотра и редактирования и выделяет исходные проёмы в Revit. Само нажатие не добавляет группу в задание размещения.

**Флажок карточки** включает все записи этой группы в создание новых перемычек. Он не означает, что группа стала активной для редактирования.

**«Выбрать все».** Устанавливает или снимает флажки только у видимых карточек первой вкладки с учётом поиска и фильтра статусов. Отметки скрытых групп сохраняются. Для полной очистки выбора сначала снимите поиск и установите «Все статусы», затем снимите «Выбрать все».

### 5.3 Поиск

Сначала выберите поле поиска, затем введите запрос. Пустая строка снимает поиск. Регистр букв не учитывается. Операторы «>», «<», диапазоны, регулярные выражения и логические выражения интерфейсом не предусмотрены.

| Поле | Где ищется |
| --- | --- |
| Все поля | Совокупность полей ниже, включая скрытые имена и ID |
| Вид проёма | Дверь, окно, витраж, сборный проём |
| Семейство/тип | Имена семейства и типа исходного объекта; также данные существующих перемычек |
| Ширина / Высота | Размеры проёма в мм |
| Опирание | Значение 0, 1 или 2 |
| Ширина опоры | Ширина несущей зоны одной из сторон |
| Тип стены | Часть имени типа стены |
| Толщина стены | Толщина стены в мм |
| Категория | Имя категории Revit |
| Уровень | Имя уровня, сохранённое в записи группы |
| Статус | Название статуса и текст состояния карточки |
| Количество | Число записей в группе |
| ID | Полный ID или его часть; для второй вкладки также ID перемычек |

Обычный запрос «150» ищет часть числовой записи и может найти 150, 1500 и 2150. Для точного числового поиска используйте «=1500». Точное сравнение допускает разницу менее 0,5 мм. Для дробных чисел поддерживаются точка и запятая. Знак «=» не делает точным поиск по текстовым полям или ID.

Примеры: «Ширина» + «=1500»; «Опирание» + «=2»; «Толщина стены» + «=380»; «Количество» + «=3».

### 5.4 Фильтр статусов

«Все статусы» показывает весь результат поиска. «Успешно», «Предупреждение», «Ошибка» оставляют карточки соответствующей категории. Фильтр относится к обеим вкладкам и действует совместно с поиском.

Если после пересчёта карточка изменила статус, она может исчезнуть из текущего фильтра. Для поиска восстановите «Все статусы». Значение статуса описано в разделе 12.1.

### 5.5 Сортировка

Блок «Сортировка» раскрывает последовательность критериев. Первый критерий «Статус» закреплён: его нельзя заменить, удалить или изменить направление. Порядок по умолчанию — успешные группы, предупреждения, ошибки. Дальнейшие критерии используются при равенстве предыдущих.

Доступны поля «Тип проёма», «Статус», «Опирание», «Ширина проёма», «Тип стены», «Толщина стены», «Категория», «Уровень», «Количество». «Добавить критерий» добавляет следующее ещё не использованное поле. «↑/↓» меняет направление выбранного дополнительного критерия; «×» удаляет его. Порядок критериев соответствует порядку строк; отдельной команды перемещения критериев нет.

### 5.6 Кнопка с лупой

На вкладке без перемычек выберите проём в Revit и нажмите лупу: плагин находит соответствующую карточку текущей выборки и прокручивает список к ней. Если она была скрыта, поиск и фильтр статусов сбрасываются.

На вкладке существующих перемычек можно выбрать в модели проём или саму перемычку. Если найдена другая запись, первое нажатие переводит к ней. Когда найденная запись уже активна, следующее нажатие выделяет только её перемычки в Revit. При отсутствии подходящего выбора может использоваться активная запись списка.

Лупа синхронизирует выбор и список. Команда не вызывает отдельное приближение камеры или «Показать элемент». Если выбраны объекты разных записей, оставьте один объект и повторите действие.

## 6 Панель Варианты раскладки

### 6.1 Геометрия и настройки

Вверху выводятся номер группы или ID, несущая сторона, несущая зона, ширина проёма, толщина и тип стены. «Обе стороны» означает опирание 2; «Сторона 1» или «Сторона 2» — опирание 1; «Не определена» и «Не требуется» соответствуют отсутствию обнаруженного опирания. «Ошибка параметров плит» требует исправления данных модели и обновления сбора.

**«Кирпич 65 мм».** Подбор по каталогу кладки с высотой ряда 65 мм. Это начальное состояние при открытии окна.

**«Кирпич 88 мм».** Подбор по каталогу кладки 88 мм.

**«Перегородки».** В текущей версии используется специальный набор перемычек «на ребро» с каталогом ряда 88 мм. Режим не означает произвольный подбор всех ненесущих изделий каталога.

**«Допуск по толщине, ± мм».** Допустимая разница между общей шириной комплекта и толщиной стены. Начальное значение 20 мм, диапазон 0–200 мм. Изменение поля пересчитывает текущую группу. Поле «Допуск» под таблицей редактора связано с тем же значением.

**«Текущий».** Заново рассчитывает варианты выбранной группы по собранной геометрии и текущим настройкам. Может заменить ручные варианты и выбранное решение этой группы.

**«Пересчитать все».** Заново рассчитывает все группы активной вкладки, включая скрытые фильтром; флажки не ограничивают операцию. После смены общих настроек применяйте эту кнопку, если нужен единый пересчёт всей вкладки.

### 6.2 Карточка варианта

Автоматический подбор возвращает до пяти вариантов. Первый обычно выбирается автоматически. Нажатие на другой вариант делает его активным только для текущей группы и заново загружает редактор.

Карточка содержит номер, состав с количеством повторений, общую ширину и отклонение, длины элементов и число штук, несущую часть и требуемую ширину, поперечную схему. «Н» обозначает несущий элемент; числа на схеме — ширины в мм; «Δ» — зазор. Несущие сегменты синие, рядовые фиолетовые, зазоры оранжевые. Подсказка сегмента показывает марку и назначение.

«Точно» означает нулевое отклонение от округлённой толщины стены. «В допуске» означает ненулевое отклонение расчётного варианта. «Предупреждение» у варианта указывает на отличие от одноимённого существующего типа. Для вручную сохранённых и металлических решений надпись «В допуске» не следует считать самостоятельной проверкой допустимости: ориентируйтесь на численные значения и особенности раздела 14.

Изображение показывает порядок элементов комплекта. При опирании с одной стороны несущая часть в схеме показывается слева; физическая ориентация экземпляра при размещении подстраивается под сторону обнаруженной опоры.

Строка под списком поясняет результат: количество найденных вариантов, отсутствие кандидатов, ошибку плит, недостаточную свободную высоту или конфликт существующего типа. Счётчик «из 5 вариантов» относится к автоматическому результату; ручное сохранение нового состава может добавить дополнительный вариант.

## 7 Редактор комплекта

### 7.1 Имя и наличие типа

Поле «Имя типа» доступно только для чтения. Имя формируется по кладке, нормализованной толщине стены, допустимому проёму и порядку элементов. Пример структуры: «65_380_1500_Б_б_б». Это пример формата, а не гарантированная марка для любого проёма 1500 мм.

Для имён толщина 400 мм приводится к 380, 500 к 510, 600 к 640. Фактическая геометрическая проверка ширины комплекта по-прежнему использует реальную толщину стены. У полностью состоящего из элементов «на ребро» комплекта появляется соответствующий суффикс.

В раскладке имени используются коды: «Б/б» для обычных брусков, «ББ/бб» для более широких элементов от 200 мм, «ППП/ппп» для плитных элементов или ширины от 350 мм. Верхний регистр у этих кодов означает несущий элемент. Также предусмотрены «У/у» для уголков, «Шв» для швеллеров, «Дв» для двутавров, «А» для арматуры, «МП» для монолитных элементов, «ПР» для прогонов, «лб» для элементов лёгкого бетона. Код зависит от описания изделия; он не заменяет чтение фактической марки.

Категория опирания готового типа выводится из верхнего регистра первого и последнего кодов раскладки: несущий код на одном краю даёт категорию 1, на обоих — 2. Для одноэлементного имени с несущим кодом получается категория 1. Поэтому правильный формат имён влияет на фильтрацию готовых типов.

| Индикатор | Значение |
| --- | --- |
| «Тип не определён» | Нет выбранной группы либо содержимого для формирования имени |
| «+ Будет создан» | Типа с таким именем нет в кэше проекта |
| «✓ Существующий тип» | Имя уже присутствует, проверяемые параметры совпадают |
| «! Существующий тип · состав отличается (N)» | Есть одноимённый тип, но найдены отличия; прочитайте расшифровку |

Сравниваются количество и порядок вложений, семейства и типы, доступные размеры, отступы между элементами, подушки и дополнительные параметры. Оранжевые строки и «!» показывают места различий. Наведение открывает подробности. Совпадение имени не означает совпадения комплекта.

### 7.2 Кнопки редактора

| Кнопка | Действие |
| --- | --- |
| Развернуть порядок | Разворачивает последовательность строк целиком; доступна при двух и более строках |
| Загрузить тип | На первой вкладке загружает фактический состав одноимённого существующего типа; доступна, если его удалось найти и прочитать |
| Вернуть расчёт | На первой вкладке снова загружает выбранный сохранённый вариант; отбрасывает несохранённые правки редактора |
| Вернуть тип | На второй вкладке загружает исходный установленный тип активной записи и сбрасывает выбранную замену в редакторе |
| Добавить перемычку | Добавляет строку на основе последнего элемента или первого доступного каталожного элемента |
| ↑ / ↓ в строке | Перемещает строку на одну позицию; крайняя кнопка направления недоступна |
| × в строке | Удаляет строку из рабочего состава; модель до применения не изменяется |

«Вернуть расчёт» не восстанавливает первоначальный автоматический вариант, если вы уже сохранили его изменения. Для нового автоматического подбора используйте «Текущий». При развороте и перемещении зазор остаётся свойством своей строки; повторно проверьте все зазоры и последний элемент.

### 7.3 Материал готового типа и доступные типы

Переключатели «Железобетон» и «Металл» фильтруют список готовых составных типов проекта. Они не переключают основной автоматический подбор на произвольный подбор металлических перемычек.

«Доступные типы» показывают семейство, имя и категорию опирания. Список учитывает выбранную кладку, признак «на ребро», толщину стены, допустимый пролёт и требуемое опирание. Для опирания 1 при отсутствии типов этой категории могут предлагаться типы категории 2; для опирания 0 приоритет имеют категории 0, затем 1, затем 2. Типы с «ошибка» в имени проходят геометрический фильтр по специальному правилу и требуют отдельной проверки.

Нажатие готового типа загружает состав в редактор. Для первой вкладки затем нажмите «Сохранить изменения варианта», для второй — «Заменить перемычки». Сам выбор карточки типа не меняет модель. При загрузке готового типа общее смещение комплекта сбрасывается к нулю.

### 7.4 Поля строки состава

Все линейные размеры таблицы задаются в миллиметрах, целыми числами. Числовые значения применяются при потере фокуса — после ввода нажмите Tab или перейдите в другое поле.

Отрицательные длина, высота, ширина и зазор нормализуются к нулю. Ноль не означает допустимый конструктивный размер. Если введены буквы или дробное число в целочисленное поле, проверьте принятие значения после выхода из поля; отдельного поясняющего диалога для каждого неверного ввода не предусмотрено.

| Столбец | Содержание и правила |
| --- | --- |
| № | Порядок вложенного элемента в комплекте; пересчитывается автоматически |
| Материал | Железобетон или металл для данной строки; влияет на список вложенных типов |
| Назначение | «Несущая» или «Ненесущая»; фильтрует подходящие элементы |
| Тип вложенной перемычки | Выбор конкретного элемента каталога с именем семейства и маркой |
| Длина | Длина элемента; для ЖБ помогает подобрать ближайший каталожный тип; для металла используется в имени и создании типа заданной длины |
| Высота | Высота элемента; изменение ЖБ запускает поиск подходящего каталожного изделия |
| Ширина | Размер элемента по толщине комплекта; влияет на итоговую ширину и подбор каталожного изделия |
| Зазор | Свободное расстояние после строки, 0 или больше; по умолчанию между новыми строками 10 мм, после последней — 0 |
| Действия | Перемещение и удаление строки |

Редактирование длины, ширины, высоты и назначения ЖБ-строки может автоматически заменить выбранную марку ближайшим подходящим изделием. Это не создание произвольного нового ЖБ-сечения. После ввода проверяйте фактически выбранный тип и размеры. При отсутствии подходящего кандидата введённые значения не гарантируют изменения геометрии загруженного семейства.

Список строк учитывает оставшуюся ширину стены с допуском и зазоры остальных элементов. Для несущей ЖБ-строки также учитывается требуемая ширина несущей зоны. При наличии металла ограничение по общей ширине ослаблено, поскольку комплект может выходить за грань стены.

Для металлической строки исходная длина обычно принимается равной ширине проёма плюс 500 мм. Изменение ширины или высоты металлической строки само по себе не создаёт новый профиль: выбор нужного сечения выполняйте через «Тип вложенной перемычки».

### 7.5 Ширина комплекта и допуск

«Стена» — округлённая толщина стены; «Комплект» — сумма ширин строк и всех указанных после них зазоров. «Отклонение» равно ширине комплекта минус толщине стены: плюс означает превышение, минус недобор.

Пример: 120 + 10 + 120 + 10 + 120 = 380 мм. Для стены 380 мм отклонение 0. Для стены 400 мм тот же комплект даёт −20 мм и укладывается в допуск ±20 мм.

Для обычного ЖБ-комплекта превышение допуска подсвечивается красным. Для комплекта с металлом индикатор считается допустимым независимо от разницы ширины: проверяйте фактический вынос и смещение. Цвет и доступность кнопки сохранения не заменяют проверку состава.

**Зазор после последней строки.** Поле разрешает его ввод и включает в итоговую ширину, однако отступ семейства записывается только между соседними вложениями. Не используйте последний зазор для имитации смещения всего комплекта. Для этого предусмотрено отдельное поле смещения у металлических решений.

### 7.6 Смещение и дополнительные параметры

**«Смещение всего комплекта относительно стены, мм».** Показывается для комплекта с металлом. Положительное значение направлено вдоль ориентации перемычки, отрицательное — в обратную сторону. Оно позволяет выпустить комплект за грань стены. Это смещение всего экземпляра, а не отдельного вложения.

**«Дополнительные параметры типа (опорные подушки и металл)».** Раскрывающийся блок. Если подушки отличаются от одноимённого типа, заголовок становится «…опорные подушки отличаются», появляется оранжевая подсветка и пояснение.

**«ОП_левая» и «ОП_правая».** Независимый выбор типов опорных подушек. «<Нет>» выключает видимость соответствующей подушки. В списке используются загруженные типы с признаками опорной подушки в имени; допускаются также определённые опорные уголки пером вниз. Левая и правая стороны относятся к локальной системе семейства.

Специально распознаются опорные уголки пером вниз 125×125×10 длиной 120 мм и 160×160×10 длиной 190 или 200 мм. Это элементы списка подушек; их не следует путать с уголками 125×125×8 для автоматического смешанного решения под низкой плитой.

**«Планка».** Доступна при наличии металла; записывает тип планки в параметр «Планка». «Не назначена» выключает «ПЛ.Видимость».

**«Раскладка планок, мм».** Расстояние между планками, записываемое в «Раскладка пл.». Отрицательное значение нормализуется к нулю.

Подушки, тип планки, её раскладка и высоты вложений являются параметрами составного типа. Изменение существующего типа влияет на все его экземпляры. Общее смещение комплекта применяется при размещении или замене экземпляра.

## 8 Создание и замена перемычек

### 8.1 Сохранение варианта

На вкладке без перемычек «Сохранить изменения варианта» переносит рабочий состав редактора в активный вариант текущей группы. Если вариант ещё не выбран, может быть добавлен новый. Другие группы не изменяются. Модель Revit на этом шаге не изменяется.

При переключении карточки, варианта, загрузке другого готового типа, восстановлении состава или пересчёте несохранённые правки редактора могут быть потеряны. Сохранение варианта действует в рамках открытого окна; отдельной команды экспорта пользовательских вариантов в файл нет.

### 8.2 Создание типов и размещение

Кнопка «Создать типы и проставить» доступна на первой вкладке, если есть хотя бы одна отмеченная группа и у всех отмеченных групп есть активный вариант и точки размещения. Статус «Предупреждение» сам по себе размещение не запрещает.

Команда берёт **сохранённые активные варианты**, а не несохранённое содержимое редактора. Для каждой группы создаётся или выбирается составной тип, затем ставится один экземпляр на каждую запись размещения этой группы.

При одной опирающейся стороне ориентация направляется к ней. Перемычка устанавливается на верх проёма относительно уровня. У нового экземпляра заполняется ADSK_Группирование = «ПР», при доступности — ZH_Этаж_Числовой, «Видимость.Глубина» = 2000 мм и «Линия обозначения.Отступ» = половина толщины комплекта. Тип основы заполняется у доступных вложений.

Номера этажей для уровней с неотрицательной отметкой назначаются по возрастанию высоты начиная с 1; для остальных используется −1. Проверьте это значение относительно правил проекта до раздельной нумерации выше и ниже нуля.

При ошибке размещения группы её экземпляры откатываются, другие группы могут завершиться успешно. Созданные или изменённые типы могут остаться в проекте даже при ошибках отдельных групп размещения. Общая ошибка операции приводит к откату её транзакций; фактический результат определяйте по отчёту и модели.

### 8.3 Совпадение имён типов

При новом размещении по рассчитанному или изменённому составу одноимённый существующий тип **синхронизируется с выбранным комплектом**. Изменения затрагивают все его экземпляры в проекте. Отдельный выбор стратегии для нового размещения интерфейс не показывает. Если сохранён неизменённый готовый тип, он используется напрямую.

На вкладке существующих перемычек при обнаруженных отличиях доступен список стратегий:

| Стратегия | Результат |
| --- | --- |
| 1. Заменить на новое | Изменяет состав существующего одноимённого типа; все экземпляры этого типа получают новые параметры |
| 2. Добавить номер к имени | Создаёт отдельный тип с суффиксом _2, _3 и далее, затем назначает его перемычкам активной записи |

По умолчанию выбрана первая стратегия. Добавление номера применяется при конфликте имени и состава; само по себе оно не создаёт дубликат неизменённого готового типа. Стратегии «Использовать существующий» и «Отмена» присутствуют в служебной логике, но не предлагаются текущим выпадающим списком.

Если несколько групп в одном задании формируют одинаковое имя, но имеют разные зазоры, подушки или другие параметры, один тип не сможет хранить несколько составов одновременно. До пакетного размещения согласуйте параметры таких групп и обязательно проверьте результат. Подробности — в разделе 14.

### 8.4 Замена существующих перемычек

На второй вкладке нижняя кнопка меняется на «Заменить перемычки», а «Создать типы и проставить» скрывается. Замена использует текущее содержимое редактора и все обнаруженные ID перемычек активной записи. Отдельное сохранение варианта перед этой кнопкой не требуется.

Команда меняет тип существующих экземпляров; при необходимости создаёт новый составной тип и применяет металлическое смещение. Ошибка отдельного экземпляра не обязательно отменяет успешные замены других. В отчёте ошибки перечисляются с ID.

«Вернуть тип» до применения восстанавливает редактор. Эта кнопка не отменяет уже выполненные изменения модели. Для отмены результата используйте обычные средства Revit с проверкой списка отменяемых операций.

### 8.5 Закрытие

«Закрыть» завершает работу окна и прерывает незавершённый фоновый расчёт. Выполненные изменения модели сохраняются в документе Revit и требуют обычного сохранения проекта. Закрытие не является отменой размещения и не экспортирует варианты.

## 9 Логика автоматического подбора

### 9.1 Сбор и объединение проёмов

Размеры читаются из параметров элемента и типа, при необходимости из габаритов. Для витража ищется стена-основа. Близкие проёмы с параллельным направлением могут объединяться в сборный, если расстояния по направлению, поперёк и по высоте не превышают 380 мм. Объединение транзитивное: цепочка близких объектов может сформировать одну запись.

Для сборного проёма ширина определяется общим диапазоном, верх — максимальным верхом, толщина стены — максимальной толщиной, а требуемые зоны опирания — наиболее требовательными значениями. Это автоматическая геометрическая обработка, поэтому проверяйте объединение на углах, примыканиях и близко стоящих проёмах.

После этого записи группируются по виду и исходному семейству/типу, типу стены, округлённым ширинам, опиранию, зонам и высотам до плит, ошибкам плит и признакам существующей перемычки. Уровень и высота проёма не являются отдельными полями ключа группировки; одна карточка может включать записи разных уровней при совпадении остальных признаков.

### 9.2 Определение плит и несущих зон

Плагин проверяет стороны стены геометрическими пробами относительно проёма. Низ опоры должен находиться выше верха проёма и в пределах предусмотренной области поиска. Предварительный сбор опор ограничен общей зоной вокруг проёмов с запасом 1000 мм в плане, 100 мм вниз и 1200 мм вверх.

Из подходящих опор по каждой стороне выбирается ближайшая по высоте; равновысотные учитываются совместно. Требуемая несущая ширина ограничивается толщиной стены. Если опора обнаружена, но её данные некорректны, подбор блокируется сообщением о параметрах плит.

Отсутствие обнаруженной опоры не доказывает отсутствие конструктивной нагрузки. Проверьте категорию, коды и геометрию плит, особенно если ожидается опирание 1 или 2, а показан 0.

### 9.3 Отбор элементов каталога

Для ЖБ проверяются материал, кладка, разрешение автоподбора, минимальная и максимальная ширина проёма и достаточная длина:

**Длина элемента ≥ ширина проёма + 2 × минимальное табличное опирание.**

Для перегородок отдельно выбираются каталожные марки с окончанием «_на ребро». Дополнительно высота несущей ЖБ-перемычки ограничивается доступным расстоянием до плиты.

Для одинаковой ширины и назначения каталог сокращается до предпочтительного представителя с учётом приоритета, достаточности пролёта и длины. Поэтому пять вариантов — это лучшие найденные комбинации выбранных представителей, а не полный перечень всех возможных изделий.

### 9.4 Формирование и ранжирование комплектов

Перебираются сочетания до 12 элементов. Между соседними единичными перемычками автоматически принимается 10 мм. Общая ширина должна попасть в толщину стены ± допуск, а несущая часть должна перекрыть требуемые зоны.

При опирании 0 обычный автоподбор использует ненесущие изделия. При опирании 1 несущая часть располагается у стороны опоры. При опирании 2 несущие элементы распределяются между двумя сторонами; одной общей суммы несущих ширин недостаточно. Возможен один несущий элемент, перекрывающий всю толщину стены.

Сначала предпочитаются минимальное отклонение ширины, затем более высокий минимальный и средний приоритет элементов, меньший излишек несущей ширины, меньшее число элементов, меньший запас допустимого пролёта, меньшее число разных марок и меньший излишек длины. После сортировки остаётся до пяти вариантов.

### 9.5 Низкая плита и смешанный комплект

Если на стороне опирания недостаточно высоты для минимальной подходящей несущей ЖБ-перемычки, предусмотрен специальный подбор уголков 125×125×8 и ЖБ-заполнения центральной зоны. Для противоположной стороны может требоваться зеркальный уголок.

Металлическая длина принимается равной ширине проёма плюс 500 мм. Уголки поднимаются к низу соответствующей плиты с учётом толщины профиля, а центральные ЖБ-элементы остаются на верху проёма. Параметры высоты первого и второго вложения и общее смещение рассчитываются автоматически.

Если нужных уголков нет в каталоге, между ними не остаётся места или центральная зона не набирается, выдаётся отдельное сообщение. Исправление требует проверки геометрии и предусмотренного проектом решения; простое увеличение допуска не гарантирует подходящего комплекта.

## 10 Сервисные операции

### 10.1 Область действия команд

Флажки слева предназначены для создания новых перемычек. Они не задают область сервисных команд.

| Команда | Какие объекты обрабатываются |
| --- | --- |
| Нумерация | Все распознанные перемычки активного документа |
| Нумерация влож. элементов | Вложения всех распознанных перемычек документа |
| Низ элемента | Перемычки из выбора Revit; если их в выборе нет — все перемычки документа |
| Тип основы | Перемычки из выбора Revit; если их в выборе нет — все перемычки документа |
| Разрезы | Перемычки всего документа с доступным значением ADSK_Позиция |
| Марки | Перемычки уровня активного плана этажа с ADSK_Позиция |
| Разрезы на листы | Разрезы проекта с «выше 0» или «ниже 0» в имени; размещение на активном листе |

Сервисное распознавание шире распознавания существующих перемычек в основном списке: достаточно ADSK_Группирование = «ПР», «Ключевая пометка» типа = «ПР» либо «Модель» типа = «Перемычки составные». Учитываются самостоятельные экземпляры несущего каркаса.

### 10.2 Разделение выше и ниже нуля

Флажок «Разбивать перемычки выше и ниже отметки 0,000» включает отдельные последовательности нумерации. По умолчанию выключен и сбрасывается при новом открытии плагина.

Разделение основано на **ZH_Этаж_Числовой**, а не на вычисленной геометрической отметке. До включения проверьте этот параметр. Для нумерации перемычек значения > 0 относятся к верхней последовательности, остальные — к нижней. При нумерации вложений используются > 0 и < 0; значение 0 не входит ни в одну последовательность. Команда разрезов использует собственное разделение по знаку параметра независимо от флажка.

### 10.3 Нумерация

Группирует все перемычки по ID типа, сортирует типы естественным порядком имён и записывает в экземплярный ADSK_Позиция значения «Пр-1», «Пр-2» и далее. Все экземпляры одного типа получают одинаковую позицию в своей последовательности. Повторный запуск перезаписывает позиции.

Если ADSK_Позиция отсутствует или недоступен для записи, конкретная запись пропускается без отдельного итогового перечня. При включённом разделении требуется корректный числовой ZH_Этаж_Числовой. Общая ошибка приводит к сообщению «Ошибка» и откату нумерации.

### 10.4 Нумерация вложенных элементов

Собирает доступные вложенные FamilyInstance у перемычек. Группирует их по типам; сортирует по ADSK_Обозначение типа, затем по имени типа; присваивает экземплярный ADSK_Позиция в виде чисел «1», «2», «3» и далее.

При разделении верхняя и нижняя группы нумеруются независимо. Один общий тип вложения может иметь разные номера в этих последовательностях. Отсутствие или недоступность ADSK_Позиция приводит к пропуску записи. Отдельного отчёта об успешной обработке нет: проверьте параметры в модели или спецификации.

### 10.5 Низ элемента

Заполняет строковый ZH_Отм_низ конструкции по сумме отметки уровня и параметра «Смещение от главной модели», с переводом в метры. Формат: «+2,100», «-0,600», три знака после запятой.

Можно выделить перемычку либо её доступное вложение: вложение поднимается до родительского экземпляра. Если в выборе есть только проёмы или посторонние элементы, команда обработает все перемычки модели. Для обработки одной записи сначала выделите её перемычки лупой на второй вкладке.

Пропускаются элементы без уровня, числового смещения и доступного строкового целевого параметра. Итоговое окно сообщает область действия, обработанное и пропущенное количество. Команда не вычисляет низ по минимальной точке фактической геометрии.

### 10.6 Тип основы

Определяет стену для выбранных перемычек либо всех перемычек модели. При необходимости ищет ближайшую подходящую стену в пределах предусмотренных геометрических допусков.

Если имя типа стены содержит «_НСЩ_», основа принимается как «Каркас», иначе — «Перегородка». Если у стены заполнен ZH_Марка КС, добавляется суффикс: например, «Каркас_КС1».

Записывает значение в ZH_Тип_Основы_Стена доступных вложений; если вложений нет, пытается записать его в сам экземпляр перемычки. Отчёт содержит число обработанных перемычек, изменённых параметров и перемычек без найденной стены. «Обработано» не означает, что у каждой перемычки был доступен целевой параметр.

### 10.7 Разрезы

Сначала выполните нумерацию и проверьте ZH_Этаж_Числовой. Команда работает со всем документом и формирует разрезы по группам ADSK_Позиция и признаку надземной/подземной части, используя первый экземпляр группы.

У первого экземпляра каждой группы «Видимость.Глубина» увеличивается до 2000 мм, если она меньше. Если параметр отсутствует, показывается предупреждение, но создание разрезов продолжается. Затем используется тип «Номер вида», шаблон «4_К_Пр», масштаб 1:20. Имена имеют вид «Пр-1 выше 0.000» или «Пр-1 ниже 0.000».

Повторный запуск анализирует совпадающие имена: может оставить существующий разрез той же позиции, переименовать конфликтующий вид либо удалить вид, где не найдена подходящая перемычка. Поэтому после повторного формирования проверьте набор видов и их размещения. Это не только добавление новых видов.

В текущем коде границы разреза явно настроены для ортогональных перемычек. Произвольный угол требует проверки; при ошибке создавайте такой разрез средствами Revit. Подготовительное изменение «Видимость.Глубина» выполняется отдельной транзакцией и может остаться после ошибки основного создания разрезов.

### 10.8 Марки и разрезы на листы

**«Марки».** Работает только на плане этажа. Обрабатывает перемычки уровня плана, а не флажки списка и не только выбор Revit. Требует «ADSK_Марка_Балка» → «ZH_Перемычка». Создаёт марки без выноски, ориентирует их по перемычке и размещает с геометрическим отступом 250 мм. Также заполняет ZH_Отм_низ конструкции.

Проверки уже существующих марок нет. Повторный запуск может создать дубликаты. Перед повторной маркировкой проверьте и при необходимости удалите прежние марки. Область сбора не ограничена видимостью элементов на плане: она определяется уровнем; элементы вне зоны видимости могут вызвать ошибку Revit.

**«Разрезы на листы».** Откройте целевой лист и заранее разместите на нём соответствующую ведомость. Команда не создаёт листы или ведомости. Разрезы с «выше 0» и «ниже 0» обрабатываются независимо и сортируются по номеру «Пр-N».

Для верхних требуется имя ведомости с «Ведомость_Пр_выше 0,00», для нижних — с «Ведомость_Пр_ниже 0,00». Из нескольких подходящих ведомостей используется первая по имени, о чём выводится предупреждение. Для разделённой ведомости точка берётся у первого сегмента.

Тип видового экрана должен иметь семейство «Видовой экран» и имя «Без названия». Разрезы ставятся фиксированной вертикальной последовательностью рядом с точкой ведомости: около 48,8 мм вправо, 45,7 мм вниз, шаг около 50,6 мм на листе. Автоматической подгонки под реальные строки ведомости, её высоту и рамку листа нет. Индекс пропущенного разреза сохраняется, поэтому в последовательности возможны промежутки.

Разрезы, уже находящиеся на текущем или другом листе, пропускаются и не перемещаются. Положение ранее размещённых видов команда не корректирует. По окончании прочитайте разворачиваемый отчёт.

### 10.9 Рекомендуемая последовательность оформления

1. Завершите размещение и замены; проверьте геометрию.
2. Проверьте ZH_Этаж_Числовой и при необходимости включите раздельную нумерацию.
3. Выполните «Нумерация» и «Нумерация влож. элементов».
4. При необходимости обновите «Низ элемента» и «Тип основы».
5. Нажмите «Разрезы», проверьте шаблоны, границы и имена.
6. На нужных планах выполните «Марки», предварительно проверив прежние марки.
7. Разместите ведомости на листах и выполните «Разрезы на листы» на каждом целевом листе.
8. Проверьте отсутствие наложений, соответствие позиций и сохраните модель.

## 11 Отчёты и сохранение результатов

### 11.1 Отчёт о простановке перемычек

После создания и размещения открывается «Отчёт о простановке перемычек». В нём указаны успешно обработанные группы, количество созданных перемычек, общая и групповые ошибки, а также раздел «Совпадения имён и различия состава».

Для конфликтов выводятся запрошенное и фактическое имя, отличия и выполненное действие. «Не обнаружены» относится именно к этому разделу, а не является заключением об отсутствии всех проблем в модели.

| Кнопка отчёта | Назначение |
| --- | --- |
| Копировать | Копирует полный текст отчёта в буфер обмена |
| Сохранить в TXT | Открывает выбор пути и записывает текст UTF-8 с автоматически предложенным именем и датой |
| Закрыть | Закрывает только окно отчёта; выполненные изменения модели остаются |

Отмена диалога сохранения не отменяет размещение. Ошибка буфера обмена или записи TXT не означает ошибку самой простановки.

### 11.2 Замена и размещение разрезов

После замены окно Revit сообщает количество заменённых экземпляров, целевой тип и ошибки по ID. При общей ошибке результат может быть отменён; при ошибке отдельного ID другие экземпляры могут быть успешно заменены.

Отчёт «Размещение разрезов» показывает лист, найденное, размещённое и пропущенное количество, ошибки. В подробностях выделены уже размещённые виды, виды на других листах, отсутствие ведомости, невозможность размещения, предупреждения и откат из-за общей ошибки.

### 11.3 Где сохраняются данные

Типы, экземпляры, позиции, параметры, разрезы и марки сохраняются в документе Revit после обычного сохранения проекта. Рабочие варианты и несохранённые правки редактора не экспортируются автоматически. TXT сохраняется только по кнопке отчёта. «Обновить», пересчёт и повторный запуск окна не заменяют сохранение файла Revit.

## 12 Состояния интерфейса и недоступные кнопки

### 12.1 Значения статусов

| Надпись или оформление | Что означает и что сделать |
| --- | --- |
| Сбор проёмов / Расчёт вариантов / Ожидает расчёта | Временное состояние; дождитесь окончания |
| Подбор перемычки не выполнен / Варианты не рассчитаны | Для записи ещё нет результата; выполните пересчёт |
| Подобрано N вар. | Активный вариант имеет точное совпадение ширины; проверьте остальной состав |
| Отклонение N мм | Активный вариант отличается по ширине; у автоматического решения отклонение находится в заданном допуске |
| Состав существующего типа отличается | Имя совпадает с типом проекта, проверяемый состав отличается; изучите сравнение |
| Варианты не найдены | Расчёт не дал варианта; причина указана в средней панели |
| Существующая перемычка не подходит | Установленный тип не прошёл проверку имени, размеров, опирания или состава |
| Доступна замена типа | Проверка существующей записи и расчёт вариантов завершены; можно подготовить замену |
| Ошибка размещения | Группа не была размещена; прочитайте отчёт |
| Размещение отменено | Операция не выполнена для группы; сообщение уточняет причину |
| Расчёт вариантов прерван | Фоновый расчёт был отменён, например закрытием окна |

Зелёный статус означает успешность предусмотренных программой проверок. Оранжевый сообщает об отклонении либо отличиях и не всегда запрещает выполнение. Красный требует выяснения причины. Отдельные сообщения «Размещение отменено» предусмотрены защитной логикой; пользовательской кнопки отмены конфликта в текущем списке стратегий нет.

### 12.2 Почему кнопка недоступна

| Элемент | Причины |
| --- | --- |
| Основная область и сервисные кнопки | Выполняется сбор, расчёт, размещение или замена |
| Текущий | Не выбрана группа, каталог пуст либо выполняется операция |
| Пересчитать все | На активной вкладке нет групп, каталог пуст либо выполняется операция |
| Сохранить изменения варианта | Не выбрана группа без перемычек, редактор пуст либо выполняется операция |
| Создать типы и проставить | Нет отмеченных групп; хотя бы у одной нет активного варианта или точки размещения; активна вторая вкладка; выполняется операция |
| Заменить перемычки | Не выбрана существующая запись, нет строк состава/ID перемычек либо выполняется операция |
| Загрузить тип | Одноимённый существующий тип не найден или не читается; на второй вкладке кнопка скрыта |
| Развернуть порядок | В редакторе меньше двух строк |
| ↑ / ↓ строки | Строка уже первая / последняя |
| Изменение первого критерия сортировки | Статус закреплён программой |

Если после исправления модели кнопка не стала доступной, нажмите «Обновить» или переоткройте окно при необходимости сменить исходный набор.

## 13 Справочник предупреждений и ошибок

В фигурных скобках ниже указаны подставляемые значения: ID, имя, размер или текст исключения. Несколько близких сообщений объединены, если причина и способ устранения одинаковы. Сообщения самой Revit API и файловой системы могут содержать произвольный технический текст; для них приведён общий порядок диагностики в подразделе 13.10.

### 13.1 Запуск и каталог

| Сообщение или начало сообщения | Причина и действие |
| --- | --- |
| В активном виде или текущем выборе не найдены поддерживаемые дверные, оконные проёмы и витражи со стеной-основой | Сбор пуст; окно закрывается. Проверьте вид, выбор, толщину и типы стен, исключения раздела 2 |
| Не найден каталог единичных перемычек LintelUnitCatalog_v3.json | Нет встроенного ресурса и резервного файла рядом с DLL. Восстановите комплект поставки плагина |
| Каталог единичных перемычек пуст или имеет неверную структуру | Каталог повреждён, пуст или несовместим. Восстановите корректный JSON |
| Ошибка каталога | Краткий индикатор ошибки загрузки. Изучите подробный текст в результате расчёта |
| Недостаточно данных для подбора комплекта | Нет каталога, запроса, положительной ширины проёма или стены. Проверьте данные и обновите сбор |

### 13.2 Плиты и отсутствие вариантов

| Сообщение или начало сообщения | Причина и действие |
| --- | --- |
| Для плиты ID {ID} не заполнен хотя бы один из параметров «Опирание 1 итог» и «Опирание 2 итог» | Прочитано нулевое/отрицательное или неразбираемое значение. Исправьте параметры типа/экземпляра плиты и обновите сбор |
| У плиты ID {ID} параметры «Опирание 1 итог» и «Опирание 2 итог» имеют разные значения | Разница больше 0,5 мм. Проверьте корректность модели и согласуйте значения, затем обновите |
| Не удалось прочитать параметры опирания плиты со стороны 1 / 2 | Опора обнаружена, корректная зона не определена. Найдите плиту и исправьте исходные параметры |
| Ошибка параметров плит | Сводная надпись при перечисленных выше ошибках; нужен повторный сбор после исправления |
| Нет перемычек для кладки {65/88} мм с длиной, достаточной для проёма и табличного опирания | Каталог не содержит подходящего изделия по ограничениям. Проверьте ширину проёма, кладку и допустимое решение |
| В каталоге нет перемычек «на ребро» с длиной, достаточной для проёма и табличного опирания | Нет кандидатов режима «Перегородки». Проверьте режим, пролёт и каталог |
| В каталоге нет перемычек для перегородок | Общее сообщение движка для запроса с нулевой высотой ряда; в основном режиме v3 используются изделия «на ребро» |
| В каталоге нет металлических перемычек, соответствующих выбранным параметрам | Служебная ветвь движка; проверьте каталог и доступные металлические элементы. Переключатель готового материала не включает общий автоподбор металла |
| Подходящие по длине элементы найдены, но среди них нет несущих перемычек для требуемой зоны | Пролёт обеспечен, несущая зона — нет. Проверьте опирание и предусмотренный проектом состав |
| Не удалось набрать толщину стены {N} мм с допуском ±{T} мм. Требуемая несущая часть… | Нет допустимой комбинации ширин/несущих зон. Проверьте толщину, кладку, зоны и каталог; меняйте допуск только в допустимых пределах решения |
| Недостаточный зазор до плиты требует металлической опоры, но в каталоге не найдены уголки 125×125×8… | Не хватает специальных уголков для низкой плиты. Проверьте каталог и проектное решение |
| После учёта опирания плит между уголками не осталось места для железобетонной перемычки | Свободная центральная зона неположительна. Проверьте толщину и опирание плит |
| Для свободной зоны между плитами шириной {N} мм не удалось подобрать ЖБ-перемычки без захода под низкую плиту | Центральная зона не набирается подходящими элементами. Дополнительная причина указана далее в сообщении |
| Недостаточный зазор определён отдельно по сторонам… Уголки подняты… | Информационный результат специального смешанного подбора. Проверьте высоты и вынос уголков на разрезе |

### 13.3 Проверка существующего типа

Следующие фразы выводятся в составе «Ошибка: …» и статуса «Существующая перемычка не подходит». Причин может быть несколько одновременно.

| Фраза | Что проверить |
| --- | --- |
| тип «{имя}» не найден среди составных типов проекта | Наличие типа, значение «Модель», актуальность сбора |
| имя типа не содержит параметры толщины стены и максимального проёма | Формат имени с разделителями и полями кладки, стены, пролёта, состава |
| в имени типа не определена толщина стены | Числовое поле толщины после первого разделителя |
| толщина типа {N} мм не соответствует стене {M} мм | Нормализованную толщину из имени и реальную стену; для «на ребро» используется допуск |
| в имени типа не определён максимальный проём | Числовое поле допустимого пролёта |
| максимальный проём типа {N} мм меньше проёма {M} мм | Выберите тип для достаточного пролёта |
| тип рассчитан для опирания {N}, требуется {M} | Состав и категорию опирания выбранного типа |
| не удалось прочитать состав существующего типа | Параметры вложенных типов, доступные компоненты и соответствие семейств |
| ширина фактического комплекта {N} мм не соответствует стене {M} мм (допуск ±{T} мм) | Реальные ширины вложений и отступы, а не только имя типа |
| вложенные перемычки рассчитаны на проём до {N} мм, фактический проём {M} мм | Каталожные ограничения всех вложений |

### 13.4 Отличия состава и редактор

| Сообщение или признак | Значение и действие |
| --- | --- |
| Тип «{имя}» уже существует, но состав отличается… | Есть конфликт параметров при совпавшем имени. Изучите строки различий и стратегию применения |
| Состав выбранного варианта отличается от существующего типа | Общее пояснение сравнения; проверьте все выделенные строки |
| Строк с отличиями… / Вложенная перемычка {N} отличается… | Различается вложенный тип, материал, размеры, назначение или отступ. «Существует» показывает текущее значение типа, «выбрано» — редактор |
| в существующем типе эта вложенная перемычка отсутствует | В редактор добавлено вложение, которого нет на этой позиции существующего типа |
| В существующем типе дополнительно… / количество вложенных перемычек: существует…, выбрано… | Количество вложений не совпадает. Проверьте перечисленные дополнительные элементы и выбранный состав |
| Опорные подушки отличаются… | Изменены ОП_левая и/или ОП_правая; они являются частью параметров типа |
| планка, её раскладка или высоты вложенных перемычек отличаются | Дополнительные параметры не совпали с готовым типом. Проверьте блок металла и исходный вариант |
| Подходящие типы не найдены | Фильтры готовых типов не дали результата. Проверьте кладку, материал, толщину, пролёт, опирание и наличие типов в проекте |
| Не удалось прочитать вложенные типы из «{имя}» | Состав выбранного готового типа не восстановлен. Проверьте семейство и параметры вложений |
| Тип «{имя}» загружен в редактор. Для применения нажмите «Сохранить изменения варианта» | Загрузка успешна; на первой вкладке сохраните вариант, на второй применяется кнопка «Заменить перемычки» |
| Изменения варианта {N} сохранены для выбранного проёма | Рабочий состав сохранён только для активной группы; модель ещё не изменена |
| В редактор возвращён исходный тип «{имя}» | Восстановлен редактор второй вкладки; это не отмена изменений модели |

| Сообщение | Действие |
| --- | --- |

### 13.10 Произвольные технические исключения

Окна «Ошибка», «Сбор проёмов», «Расчёт вариантов», «Поиск проёма», «Низ элемента», «Тип основы» и окна сервисных операций могут показывать исходный текст исключения Revit, WPF, JSON или файловой системы. Такие тексты не ограничены фиксированным списком строк плагина.

1. Сохраните текст, название операции, тип и ID проблемного элемента.
2. Проверьте, какие изменения действительно появились в модели. Ошибка обновления окна или сохранения отчёта не отменяет успешно изменённую модель.
3. Завершите незаконченные команды и диалоги Revit; проверьте доступность элементов для редактирования.
4. Для ошибки параметра проверьте его наличие, тип данных, уровень «тип/экземпляр», формулу и доступность записи.
5. После исправления геометрии используйте «Обновить»; после смены исходного выбора или загрузки новых подушек/планок переоткройте окно.
6. Повторите на одной группе или одном экземпляре. Перед повторной маркировкой проверьте дубликаты; перед повторным размещением — уже созданные перемычки.
7. Если ошибка повторяется, передайте сопровождающему текст, ID, семейство и тип, сценарий и минимальный пример модели.

## 14 Особенности и ограничения текущей версии

### 14.1 Обновление и сохранение

«Сохранить изменения варианта» не создаёт файл пользовательских настроек. Повторный сбор перестраивает группы; пересчёт заменяет их расчётные варианты. Храните важные результаты в модели и при необходимости сохраняйте отчёт. Предупреждения о потере каждой несохранённой правки нет.

При смене кладки или допуска автоматически пересчитывается текущая группа. Остальные группы могут сохранять варианты, рассчитанные с прежними настройками. Перед массовым размещением используйте «Пересчитать все» и повторно проверьте ручные изменения.

### 14.2 Ручные правки и контроль допустимости

Ручное сохранение не повторяет весь набор ограничений автоматического перебора. Кнопка размещения проверяет наличие вариантов и точек размещения, а не полную конструктивную пригодность. Вручную изменённый комплект может сохранить недопустимую ширину или несущую часть. Проверяйте численные данные, длины, профиль, расположение несущих элементов и соответствие проекту.

Для металла зелёный индикатор ширины означает специальное разрешение выхода за грань стены. Он не подтверждает достаточность сечения, длины, высоты или опирания. Для ЖБ введённые размеры прежде всего управляют выбором каталожного типа; произвольная геометрия по ним не создаётся.

### 14.3 Имя не кодирует все параметры

Имя комплекта не содержит все зазоры, типы подушек, параметры планки и индивидуальные высоты. Разные решения могут иметь одинаковое имя. При новом размещении тип с совпадающим именем может быть перенастроен; его существующие экземпляры изменятся.

Особенно проверяйте группы с одинаковыми именами в одном задании: последовательная настройка общего типа может привести к тому, что итоговые экземпляры используют параметры последней обработанной группы. Плагин не создаёт автоматически отдельное уникальное имя для каждого различия новых комплектов.

### 14.4 Геометрическое распознавание

Объединение близких проёмов не требует строгого равенства ID стен. Группировка одинаковых записей не разделяет их по уровню и высоте проёма. Обнаружение существующих перемычек основано на пересечении габаритов рядом с верхом проёма. Поэтому одинаковые карточки, составные проёмы и автоматически найденные связи всегда проверяйте по ID в модели.

Для распознавания существующей перемычки основным списком нужны: самостоятельный экземпляр несущего каркаса; имя семейства с «_Перемычки» либо модель типа «Перемычки составные»; ADSK_Группирование = «ПР»; пересечение поисковой зоны. Иная вручную установленная перемычка может не попасть во вторую вкладку.

### 14.5 Разделение по нулю и оформление

Нумерация, нумерация вложений и создание разрезов немного различаются в обработке ZH_Этаж_Числовой = 0. Не используйте нулевое значение как неопределённое, если ожидаете согласованную раздельную нумерацию.

Повторная маркировка не удаляет старые марки. Повторное создание разрезов может менять или удалять конфликтующие виды. Размещение на листы ориентируется на имена и фиксированный шаг, а не на фактическое содержимое строк ведомости. Для повернутых перемычек особенно проверяйте команду «Разрезы».

## 15 Практические сценарии

### 15.1 Подобрать одну группу и проверить результат

Выделите один поддерживаемый проём перед запуском. После расчёта проверьте стену и опирание. Выберите вариант, при необходимости исправьте редактор и сохраните вариант. Поставьте флажок и выполните создание. Сопоставьте ширину, отметку, поворот и вложенные типы с расчётной карточкой. Затем переходите к массовой обработке.

### 15.2 Поменять только отмеченную часть новых проёмов

В первой вкладке отфильтруйте нужную толщину или тип стены. «Выбрать все» отметит видимые группы. Подготовьте для них активные варианты. Перед созданием снимите фильтр и проверьте, не осталось ли отмеченных посторонних групп. Нажмите создание; фильтр сам по себе не ограничивает задание.

### 15.3 Заменить одну существующую запись без изменения общего типа

Выберите запись второй вкладки, восстановите установленный состав через «Вернуть тип» и внесите изменения. При конфликте одноимённого типа выберите «Добавить номер к имени». Нажмите «Заменить перемычки». Проверьте, что создан отдельный тип, а остальные экземпляры прежнего типа сохранили состав.

### 15.4 Исправить параметры плиты

Сохраните ID из сообщения, найдите плиту средствами Revit и проверьте «Опирание 1 итог» и «Опирание 2 итог» в типе, затем в экземпляре. Исправьте согласованные значения. В плагине нажмите «Обновить», дождитесь нового расчёта и проверьте несущие зоны. Повторять только «Текущий» до нового сбора недостаточно.

### 15.5 Заполнить отметку только выбранных перемычек

На второй вкладке выберите карточку и нажмите лупу, чтобы в Revit выделились её перемычки. Нажмите «Низ элемента». В итоговом диалоге убедитесь, что указана обработка выбранных перемычек. Если в выборе остались только проёмы, будет использована вся модель.

### 15.6 Оформить разрезы на листе

Завершите нумерацию, создайте и проверьте разрезы. На лист поместите верхнюю и/или нижнюю ведомость с нужными именами. Откройте этот лист, нажмите «Разрезы на листы», раскройте подробности. Проверьте, какие виды уже на других листах, и вручную уточните расположение новых видовых экранов относительно строк ведомости.

| Параметры выбора вложенных типов 1ПР, 2ПР и далее | Должны соответствовать распознаваемым слотам и принимать ID единичных семейств |
| 2ПР.Видимость, 3ПР.Видимость и далее | Управляют используемыми и лишними вложениями |
| Отступ от 1 до 2, Отступ от 2 до 3 и далее | Ширина предшествующего элемента плюс зазор |
| Длина главной(первой) перемычки | Записываемая длина; устанавливается по самому длинному вложению |
| ОП_левая / ОП_правая | Выбор типа соответствующей подушки |
| ОП-1-Л.Видимость / ОП-1-П.Видимость | Управление видимостью подушек |
| Планка / ПЛ.Видимость / Раскладка пл. | Тип, видимость и шаг планок |
| Высота 1 перемычки / Высота 2 перемычки | Дополнительные высоты первого/второго элемента для специальных решений |
| ADSK_Размер_Длина | Записываемая длина типа металлического единичного семейства |

Параметры с формулами или только для чтения не могут использоваться там, где плагин должен записывать значения. Наличие похожего имени не всегда означает совместимость: важны тип данных, категория вложения и устройство семейства.

## 17 Проверка результата

Перед применением убедитесь, что выбрана правильная область сбора, понятны автоматически объединённые проёмы, корректны плиты и опирание, все нужные группы имеют активный вариант, а правки редактора сохранены. Проверьте скрытые флажки и влияние одноимённых типов.

После размещения проверьте положение на верху проёма, поворот к опоре, длину и опирание на простенки, число и порядок вложений, межэлементные зазоры, ширину комплекта, вынос металла, подушки и планки. Сопоставьте количество успешных записей с отчётом.

После оформления проверьте позиции и числовой этаж, отметки низа, тип основы, дубликаты марок, имена и границы разрезов, шаблон и масштаб, соответствие ведомостям, размещение по листам и отсутствие наложений. Сохраните документ Revit и отчёт при необходимости.

## 18 Источники и границы руководства

Руководство относится к рабочему окну LintelCreator v3 и его обработчикам. Основные точки сопровождения:

| Файл | Что определяет |
| --- | --- |
| LintelCreatorForm_v3.xaml | Видимый интерфейс, подписи, подсказки, условия показа элементов |
| LintelCreatorForm_v3.xaml.cs | Обработчики кнопок, синхронизацию с Revit, окно отчёта |
| CommandLintelCreator_v3.cs | Сбор, группировку, редактор, создание и замену, сообщения и параметры |
| LintelSelectionV3.cs | Ограничения и ранжирование каталожного подбора |
| LintelServiceOperationsV3.cs | Нумерацию, отметки, тип основы, разрезы, марки и листы |
| LintelUnitCatalog_v3.json | Характеристики единичных элементов каталога |

LintelLayoutPrototype.xaml — отдельный прототип; его элементы не считаются рабочими кнопками текущего окна. Пути установки, версия Revit и название кнопки ленты определяются внешней сборкой и развёртыванием FerrumAddin, поэтому в руководстве не задаётся неподтверждённый номер версии или путь установки.

При изменении кода или каталога обновляйте руководство. Полнота справочника относится к явно заданным сообщениям и предусмотренным ветвям плагина; произвольные исключения Revit и системных компонентов разбираются по общему порядку диагностики.
